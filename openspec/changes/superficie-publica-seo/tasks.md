## 1. Base de datos

- [ ] 1.1 Crear `supabase/migrations/0038_superficie_publica_seo.sql`, aditiva e idempotente, número estrictamente mayor que `0037`. Primer bloque: `alter table obras add column if not exists publicacion_web boolean not null default true;`. Verificar con `information_schema.columns` que la columna existe con default `true`.
- [ ] 1.2 En la misma migración: `create or replace function public.convocatorias_publicas(p_texto text default null, p_ciudad text default null, p_limite int default 24, p_desfase int default 0)` `language sql`, `security definer`, `stable`, `set search_path = public`. Devuelve `id uuid, titulo text, sinopsis text, ciudad text, fecha_estreno_estimada date, actualizado_en timestamptz, creador_nombre text, creador_disciplinas disciplina_artistica[], roles_abiertos int`, join `obras`↔`perfiles_creador`, `where estado = 'publicada' and publicacion_web`, filtros `ilike` opcionales sobre `titulo` y `ubicacion_publica`, `order by actualizado_en desc, id`, `limit least(greatest(p_limite,1),48) offset greatest(p_desfase,0)`. Nunca devuelve `locacion_ensayos`, `ubicacion_texto`, `ubicacion_lat/lng`, `creador_id`.
- [ ] 1.3 En la misma migración: `create or replace function public.convocatoria_publica(p_id uuid)` con las mismas garantías, que además trae `creador_ciudad text` y el array de roles (`nombre, tipo, edad_minima, edad_maxima, vacantes, descripcion`), `where o.id = p_id and o.estado = 'publicada' and o.publicacion_web`. Sin fila que cumpla → devuelve 0 filas (la página hará `notFound()`).
- [ ] 1.4 En la misma migración: `revoke all on function public.convocatorias_publicas(text,text,int,int) from public;` y `revoke all on function public.convocatoria_publica(uuid) from public;`, luego `grant execute ... to anon, authenticated;` para ambas. No se agrega ninguna policy de lectura anónima sobre `obras`, `roles` ni `perfiles_creador`.
- [ ] 1.5 Aplicar `0038` a producción (Management API con el PAT de `~/.soliloq-deploy/supabase-token.txt`, ver memoria de deploy) y registrar la fila en `supabase_migrations.schema_migrations`.
